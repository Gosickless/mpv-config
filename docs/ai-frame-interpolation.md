# AI 补帧组件管理与测试说明

AI 补帧是独立功能，不属于画质预设。右键菜单有“AI补帧：关闭/开启”和“补帧组件：未安装/已安装”。点击组件这一项始终打开同一个组件管理窗口。

## 安装窗口

首次打开仅显示信息，不自动下载：约2.63 GiB下载量、至少12 GiB可用空间要求和实际安装目录。点击“开始安装”才开始。窗口显示下载进度条、百分比与已下载/总量。

- 下载中可点“暂停下载”；暂停后点“继续下载”。已下载内容保留，支持HTTP断点续传；服务器不接受续传时会安全地重新下载当前文件。
- 校验和解压阶段显示“检查文件/正在安装”；这两步不提供暂停，窗口保持响应。
- 关闭未完成的安装窗口会先询问，确认后停止任务并保留下载内容。若正在解压，可能需要等当前步骤结束。
- 完成后窗口显示“AI补帧组件已安装”，按钮变为“打开播放器”，不再显示脚本路径或开发测试信息。
- 之后再点右键菜单中的组件项，直接显示已安装状态、安装位置和安装时间。不会重新下载。
- “查看详情”中提供组件版本和错误/日志位置，普通流程无需理解Python、VapourSynth或TensorRT。

“打开播放器”会在新窗口应用组件，不强行关闭当前播放。然后打开视频，通过右键补帧开关启用。首次为该规格视频准备模型可能需要等待，播放器显示“正在准备”；正常完成后显示“开启”。画质可选轻量、均衡和高画质；输出可选自动两倍或24–360之间的整数目标，按最接近的半倍档计算，例如23.976输入选择60时实际约59.940 fps。

## 安装位置

安装目录默认 `%LOCALAPPDATA%\mpv-rife`。家里账号如果是Gosickless，对应 `C:\Users\Gosickless\AppData\Local\mpv-rife`。目录可由实际配置目录内 `script-opts\rife.conf` 的 `runtime_root=` 指定；留空使用默认。

## 已实现但尚未完成目标硬件验收

当前分支是实验实现，不是正式发布：

- Python3.13.9、VapourSynthR79、vs-mlrt15.16（CUDA13.2/TensorRT10.16.0）固定下载源和SHA256，环境独立，不改系统Python/PATH。
- 下载管理窗口、真实暂停/续传、校验、安装锁、版本化环境和失败不覆盖旧安装。成功、失败或取消后清理本次解压目录；已下载文件保留用于续传或重装。旧版本组件会重新提供安装入口。
- 独立补帧开关、模型准备进程、旧文件任务作废、仅操作自己的 `@mpv_rife` 滤镜；已有其他vf时拒绝盲目组合。
- 固定下载RIFE4.25的轻量、均衡和高画质模型；使用内部补边实现保持原分辨率，返回10位输出。接受偶数尺寸最高3840×2160、1–30fps逐行输入。
- 按运行库、GPU及驱动、尺寸和模型隔离引擎缓存；准备与读取共享跨进程锁，取得真实推理帧后才原子发布。取消准备留下的工作目录在下次获取同一锁后清理。

已在RTX5070验证全新安装、1080p SDR标准模型推理、约47.952/59.940 fps无窗口输出、暂停、拖动、倍速切换和关闭。无窗口短样本仍观察到掉帧，生成帧率不等于屏幕呈现帧率。仍待验证1440p/4K实时性能、显存释放、长片/切集/片尾、HDR10画质/静态元数据/实显。

## HDR10与输入限制

HDR10候选链保留浮点PQ编码RGB后回到10位YUV。按用户选择，默认 `experimental_hdr=yes`，开启补帧时允许HDR10进入实验处理链；需要关闭时可在 `script-opts\rife.conf` 改为 `no`。杜比视界与HLG暂不处理，HDR画质与静态元数据仍未完成验收。

CPU测试确认标准mpv0.42.0经过不含RIFE的颜色往返链后，PQ、BT.2020、矩阵及10位标记可保留；不代表真实AI插帧后的亮度/颜色和HDR静态元数据已验证。帧时长检查不能仅靠平均帧率证明所有片源是CFR，真实VFR及片尾仍待测试。

## 运行环境与维护

- `runtime/`：版本化Python、VS、推理库、上游许可；`active.json`记录当前版本。
- `cache/`：按规格和GPU隔离的本机TensorRT引擎、锁和完成记录，不应跨机器直接复制。
- `downloads/`：已校验下载包和可继续的`.part`；`staging/`：临时解包目录。
- `jobs/`：每次安装独立的进度、控制标记和日志，避免旧进度污染新窗口。
- `prepare-*.jsonl.stderr`：模型准备错误。分享日志前检查本机路径等私有信息。

关闭补帧不影响画质预设、音量和字幕。新进程默认关闭。运行库可能驻留进程，退出mpv是彻底清理加载库的边界；不能仅凭菜单“关闭”宣称显存完全释放。

当前不提供自动卸载/旧环境回收。需要清理时应先关闭使用该环境的播放器与准备进程，备份需要的日志，再处理明确的环境目录，不删除mpv配置。

## 开发测试记录

- `python -B tests/test_rife_policy.py`：输入范围和HDR实验门禁。
- `python -B tests/test_rife_download.py`：本地HTTP真实暂停/续传、服务器忽略Range时的安全重下和最终SHA256；不下载上游包。
- `python -B tests/test_rife_manager.py`：首次查看不触发安装、中文路径的已安装记录正确打开状态页；使用隔离夹具，不表示真正安装过完整环境。
- `python -B tests/test_rife_engine_cache.py`：跨进程等待、原子发布、失败重试、取消恢复与GPU/模型隔离。
- `python -B tests/test_rife_staging.py`：清理范围保护、真实安装解压失败时清理和保留旧版本/下载包。
- Lua控制、PowerShell解析及上述1080p GPU播放流程已验证；剩余硬件和HDR项目如上。

依赖采用Python、VapourSynth、AmusementClub/vs-mlrt官方发布资产；上游模型/推理库许可随包提供。源代码中的 `launch.ps1` 是高级手动入口，普通用户使用窗口“打开播放器”即可。
